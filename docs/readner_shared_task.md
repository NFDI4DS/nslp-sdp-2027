<h1>Shared Task on README Named Entity Recognition</h1>
</div>


READNER addresses fine-grained named entity recognition in research-related GitHub README files, where metadata about datasets, software, experimental code, and other research artifacts is often embedded in free-form documentation. 
The task builds on NERdME, comprising 200 manually annotated READMEs with 10,691 mentions across 10 entity type. Participants identify entity mentions and their boundaries. By covering both paper-level and implementation-level research entities, NERdME bridges scientific information extraction and software-repository documentation. Existing LLM and transformer baselines leave substantial room for improvement, particularly in exact-boundary recognition.
